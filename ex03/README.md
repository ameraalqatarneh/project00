 Introduction
This project demonstrates Git version control and GitHub using SSH.

Why Git Makes Development Easier
Git tracks changes and keeps a history of the project.
It helps recover previous versions and makes collaboration easier.

Git Workflow
Edit files
git add
git commit
git push

SSH Authentication
SSH provides secure authentication with GitHub using an Ed25519 key pair.
The private key must remain secret.

Security
Never commit or share the private SSH key.

Conclusion
This project demonstrates Git, GitHub, Markdown, and secure SSH authentication.
